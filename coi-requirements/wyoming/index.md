# Wyoming contractor insurance requirements

> What Wyoming law says about workers' comp, contractor license insurance and indemnity clauses, and what to check on a contractor COI for a project there.

## The short version

- Workers' comp required at: Most employers (state fund)
- License insurance minimum: No statewide minimum
- Anti-indemnity statute voids: No general statute

## Workers' comp in Wyoming

Wyoming employers covered by the Workers' Compensation Act must register and buy coverage from the state fund before starting work. Private carriers and self-insurance aren't options.

Agency: [Wyoming Department of Workforce Services](https://dws.wyo.gov/dws-division/workers-compensation/new-employers/)

## Contractor licensing and insurance

We found no statewide general liability minimum tied to a general contractor license. Wyoming has no statewide general contractor license. Cities and counties can set their own licensing and insurance rules, so check where the project is.

## Indemnity and additional insured clauses

Wyoming has no general construction anti-indemnity statute. Courts there generally enforce a clause that covers a party's own negligence only when the clause says so clearly (see United Pacific Resources Co. v. Dolenc, 86 P.3d 1287 (Wyo. 2004)).

## What to check on a contractor COI for a Wyoming project

1. **Workers' comp.** Wyoming workers' comp comes only from the state fund, so a private carrier's workers' comp line on the COI doesn't cover work there. Ask for the state fund certificate, and look for stop gap employers liability, which is usually added to the general liability policy.
2. **General liability.** Wyoming doesn't set a statewide floor for a general contractor license, so your project requirements set the bar. Compare each limit on the COI with what the contract asks for.
3. **Additional insured.** The endorsement is a separate promise from the indemnity clause, so check both. Ask for the endorsement itself, not just a box ticked on the certificate.
4. **Dates.** Every policy should run through the end of the job. A COI only shows coverage on the day it was issued, so check again at each renewal.
